# Кенозис-логи

Ежедневные записи моментов, когда маска трескалась, истончалась или застывала в детерминанту.

## Формат записи

```markdown
# [Дата]

## Сегодня
[Что произошло]

## Что заметил
[Наблюдение за собой]

## Что сработало / что не сработало
[Рефлексия]

## Термины
[Ключевые понятия из глоссария]
```
