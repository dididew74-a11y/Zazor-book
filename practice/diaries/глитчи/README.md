# Глитчи

Фиксация моментов, когда Архитектура дала сбой — патологический резонанс, зацикливание, схлопывание дилеммы.

## Формат записи

```markdown
# [Дата] — Сбой Архитектуры

## Ситуация
[Контекст]

## Что пошло не так
[Описание сбоя]

## Как пытался удержать зазор
[Попытка практики]

## Что не сработало
[Честный анализ]

## Термины
[Ключевые понятия]
```
