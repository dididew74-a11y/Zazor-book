# Возвращение

Записи о том, как практика входит в социальную реальность — где она работает, где не работает, где возникают новые формы детерминанты.

## Формат записи

```markdown
# [Дата] — [Название ситуации]

## Ситуация
[Контекст]

## Что сделал
[Применение практики]

## Что произошло
[Реакция среды]

## Рефлексия
[Честный анализ]
```
